# Очередь ОПИ

Сервис для удобной записи в очередь на выступления и распределения тем докладов внутри учебной группы. Работает как Telegram Mini App на базе Vercel
и облачной БД Redis без необходимости держать включенный сервер 24/7 (но также это накладывает ограничение на количество запросов в месяц).

### Основные возможности

* **Запись без дубликатов:** место в очереди и тема закрепляются за конкретным студентом; серверная блокировка исключает конфликты при одновременном нажатии в одну миллисекунду.
* **Умный повтор тем:** выбор уже занятых тем заблокирован до тех пор, пока не закончатся уникальные варианты. При переходе на второй круг темы открываются повторно, а в итоговой таблице появляется отметка.
* **Live-обновление:** таблица синхронизируется в реальном времени с интервалом 1.5 секунды без сброса открытого списка выбора.
* **Панель старосты:** защищенный вход для создания новых очередей (с индивидуальным списком тем и количеством мест), удаления завершенных списков и точечной очистки мест.
* **Автоматические уведомления:** бот отправляет оповещения в личные сообщения участникам при публикации новой записи.
* **Кроссплатформенность:** интерфейс адаптивный, что позволяет использовать это miniapps на любых устройствах.
